# Context and retrieval

> Working with context thoughtfully.

Canonical page: https://rajakarthik.com/work/memory-retrieval/

## Overview

More context does not automatically make an answer better. The challenge is selecting relevant information, interpreting it carefully, and knowing when uncertainty remains.

My interests include information retrieval, source attribution, changing information, and evaluating whether retrieved context actually helps.

## Topics I explore

- Relevance and source attribution
- Handling stale or conflicting information
- Precision versus completeness in retrieval
- User control and sensible uncertainty

A good system should know when it has enough context—and when it does not.
